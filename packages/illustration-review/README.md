# Local technical illustration review

This passive product consumer joins the installed Conjunct illustration CLI,
its document adapter and DocShell's artifact admission/export path. The inputs
under `data/illustrations/synthetic-photo-frame` are authored software fixtures.
Their physical checks and procedure readiness remain unknown.

Install the exact producer archives before running. `DOC_SHELL_SOURCE`,
`CONJUNCT_WIRE_SOURCE` and `CONJUNCT_ILLUSTRATION_SOURCE` are explicit development
or unpacked-archive overrides; publication dependencies contain no machine paths.
The selected source must include the new capability, which is not a claim about
an existing public release.

```sh
export DOC_SHELL_SOURCE=/absolute/installed/doc_shell
export CONJUNCT_WIRE_SOURCE=/absolute/installed/conjunct_wire
export CONJUNCT_ILLUSTRATION_SOURCE=/absolute/installed/conjunct_illustration
(cd packages/illustration-review && MIX_ENV=prod mise exec -- mix deps.get)
./scripts/illustrations /absolute/path/conjunct-illustrate /absolute/new/output
```

The command creates a real producer packet and a verified static document.
The document uses file-relative assets so it can be opened from its local
`document/index.html`. Checkpoints, procedure selections, connector inspection,
dark and monochrome states, contact sheets and 4× vector crops are generated
from the same committed scene. The source generator is `scripts/fixtures.exs`
inside this package; regenerating inputs requires the exact producer descriptor.

The renderer consumes checked DocShell receipts; it does not implement scene
semantics. Failed required bindings or bytes stop publication. Run comparison
with the producer's public `compare` command; baseline approval is separate.
With the same installed dependency overrides, verify the completed output from
this package using `MIX_ENV=prod mise exec -- mix run scripts/verify.exs /absolute/review`.
The command verifies actual packet/site bytes, source-bound semantics and static
admission receipts, and prints a replay observation. Retained records live with
the [inputs](../../data/illustrations/README.md).
The BOE candidate generator is `scripts/panel_candidate.exs`: pass the producer
descriptor, retained `boe-mv270qhm-n40-p1/dimensions.json` and a new destination.
It produces an outline envelope and a detached active-area inspection plane at
the exact nominal source dimensions. The one-micrometre active-area slab and its
offset are presentation geometry. Regional protrusions have no invented
locations. The derived wooden enclosure remains unknown because the complete
installed panel and electronics, glazing, mat, retention and clearance inputs
are unresolved. The default theme is monochrome; material colour is an explicit
alternate state. `scripts/illustrations` accepts an optional third absolute
fixture argument to export these carriers through the same producer/document join.

Conjunct's macOS native frontend accepts these same original scene/state files.
Its window, input and process transport are host-owned; all geometry and motion
remain in the producer. Additional targets, browser/manual assistive tasks,
complete lifecycle qualification and physical qualification remain open in the
existing delivery plan.
